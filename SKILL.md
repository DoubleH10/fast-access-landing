If creating visual artifacts (slides, mocks, throwaway prototypes, etc.), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

Key conventions to follow:

- **Colors:** Liberty Blue `#0D1232`, Blue Rose `#2D2E75`, Orange Soda `#F15B41`. Paper `#F3F2EC` for warm cream surfaces. Orange is the only accent — never tint or gradient it.
- **Type:** Clash Grotesk Medium for display/headings (110% leading, −2% tracking), Inter/Inter Display for UI and body (128% subhead, 140% body, −2% tracking).
- **Buttons:** uppercase, +6% tracking, with a small orange tile holding a `→` at the right end for primary CTAs.
- **Tone:** confident, technical, premium. Sentence case headlines. Second-person. No emoji, no exclamation marks, no logistics clichés.
- **Motion:** cubic-out easings, 140–900ms. The signature "moving package" travels through the page on scroll.
- **Iconography:** Lucide (substituted — flag this if asked). 1.75 px stroke. No emoji.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some clarifying questions (audience, surface, fidelity, length), then act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
